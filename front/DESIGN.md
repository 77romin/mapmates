# DESIGN.md · 너랑 갈.지도

Airbnb 디자인 기준안(awesome-claude-design, getdesign.md)의 원칙을 Mapmates 브랜드에 맞게 옮긴 문서다.
Airbnb의 색과 서체를 그대로 쓰지 않는다. 가져온 것은 **흰 캔버스, 사진 우선, 포인트 색 하나, 둥근 모서리, 절제된 그림자**라는 원칙이다.
토큰의 실제 값은 `src/style.css`의 `:root`가 기준이며, 이 문서와 어긋나면 이 문서를 먼저 고친 뒤 CSS를 맞춘다.

> 원본 Airbnb DESIGN.md는 이 저장소에 들어 있지 않다. 필요하면 `npx getdesign@latest add airbnb`로 받아 참고용으로만 둔다.
> 아래 값 가운데 Airbnb 원본과 대조하지 못한 항목(중립 회색, 그림자 수치)은 원본을 받은 뒤 한 번 맞춰 본다.

## 1. 분위기

- 화면의 주인공은 지도와 장소 사진이다. UI는 뒤로 물러난다.
- 바탕은 흰색, 글자는 짙은 네이비와 거의 검정. 색은 코랄 하나만 쓴다.
- 그라데이션, 유리 효과, 커서를 따라다니는 빛 효과는 쓰지 않는다.

## 2. 색

| 역할 | 변수 | 값 | 쓰는 곳 |
|---|---|---|---|
| 바탕 | `--mm-bg` | `#ffffff` | 페이지, 카드, 패널 |
| 보조 바탕 | `--mm-surface` | `#f7f7f7` | 사진 자리, hover, 인증 화면 배경 |
| 구분선 | `--mm-line` | `#ebebeb` | 카드·패널 테두리 |
| 진한 구분선 | `--mm-line-strong` | `#dddddd` | 입력창·버튼 테두리 |
| 제목 | `--mm-ink` | `#1f2a44` | 제목, 선택된 칩, 챗봇 헤더 (로고의 네이비) |
| 본문 | `--mm-text` | `#222222` | 본문 |
| 보조 글자 | `--mm-muted` | `#6a6a6a` | 주소, 날짜, 설명 (흰 바탕 대비 5.4:1) |
| 장식 | `--mm-placeholder` | `#b0b0b0` | 사진 없음 아이콘. 글자에는 쓰지 않는다 |
| 포인트(장식) | `--mm-coral` | `#ff6b4a` | 지도 핀 테두리, 경로선, 포커스 링 |
| 포인트(버튼·글자) | `--mm-coral-dark` | `#c93d22` | 주요 버튼, 코랄 글자, 번호 배지 (흰색과 대비 5.0:1) |
| 포인트 hover | `--mm-coral-darker` | `#ad3219` | 버튼 hover |
| 포인트 옅은 배경 | `--mm-coral-tint` | `#fff1ec` | 배지 |
| 상태 | `--mm-success` `--mm-danger` | `#0f9d76` `#a12828` | 집결지 핀, 오류 |

밝은 코랄(`--mm-coral`) 위에 흰 글자를 올리지 않는다. 대비가 2.8:1이라 읽기 어렵다.

## 3. 글자

- 서체는 Pretendard 하나.
- 크기는 5단계만 쓴다: `--mm-fs-xs` 12px, `--mm-fs-sm` 14px, `--mm-fs-md` 16px, `--mm-fs-lg` 20px, `--mm-fs-xl` 26px.
- 제목은 굵기 700, 자간 -0.02em, 색 `--mm-ink`. 제목에 그라데이션을 쓰지 않는다.
- 한 카드 안에서 위계는 3단계까지: 제목(16px 이상, 굵게) → 핵심 정보(14px, 본문 색) → 부가 정보(12~14px, 보조 색).
- `small text-secondary`를 기본값처럼 쓰지 않는다. 부가 정보에만 쓴다.

## 4. 컴포넌트

- **주요 버튼** `.btn-coral`: 단색 `--mm-coral-dark`, 흰 글자, 굵기 600. 한 화면에 하나만 둔다.
- **보조 버튼** `.btn-outline-coral`, `.btn-light`: 테두리만 또는 옅은 회색 바탕.
- **칩**: 알약 모양. 선택되면 `--mm-ink` 바탕에 흰 글자.
- **카드** `.mm-card`: 흰 바탕, 1px `--mm-line`, 모서리 14px, 평소엔 그림자 없음. hover에서만 `--mm-shadow-2`.
- **목록 항목** `.mm-item`: 72px 사진 + 제목 + 주소. hover는 `--mm-surface`.
- **사진**: 모서리 14px. 사진이 없으면 `--mm-surface` 바탕에 유형 아이콘.
- **모달**: 모서리 20px, `--mm-shadow-3`, 배경은 검정 45%.

## 5. 레이아웃

- 지도 화면: 왼쪽 400px 패널 + 나머지 지도. 패널 안에서 목록 → 상세 → 편집으로 바뀐다.
- 목록 화면: 최대 폭 1040px, 3열 카드(992px 이상), 2열(768px 이상), 1열.
- 간격은 4·8·12·16·24·32·48px(`--mm-sp-1`~`--mm-sp-7`)만 쓴다.

## 6. 깊이

| 단계 | 변수 | 쓰는 곳 |
|---|---|---|
| 1 | `--mm-shadow-1` | 스크롤된 헤더, 작은 떠 있는 버튼 |
| 2 | `--mm-shadow-2` | 카드 hover, 지도 위 버튼, 챗봇 버튼 |
| 3 | `--mm-shadow-3` | 모달, 챗봇 창 |

## 7. 할 것과 하지 말 것

할 것
- 사진이 있으면 사진을 가장 크게 보여 준다.
- 값은 변수로만 쓴다. `.vue` 파일에 색·모서리·그림자 값을 직접 적지 않는다.
- 색만으로 상태를 구분하지 않는다. 배지 문구를 함께 둔다.

하지 말 것
- 그라데이션 배경·버튼·글자.
- 한 화면에 주요 버튼 두 개 이상.
- 모서리·글자 크기를 단계 밖 값으로 새로 만들기.
- 장식용 모션 추가. 모션은 순차 등장, 줄어드는 헤더, 메뉴 밑줄 세 가지뿐이다.

## 8. 반응형

- 768px 미만: 지도가 위(42vh), 패널이 아래. 메뉴는 햄버거.
- 터치 기기와 '움직임 줄이기' 설정에서는 모션을 끈다.
- 확인 폭: 375, 768, 1024, 1440px.

## 9. 에이전트에게

- 새 화면이나 컴포넌트를 만들 때 이 문서와 `src/style.css`의 변수만 쓴다.
- Bootstrap 5는 유지한다. 격자와 폼은 Bootstrap, 색·모서리·그림자는 `--mm-*` 변수.
- 끝내기 전 확인: 글자 대비 4.5:1 이상, 키보드 포커스가 보이는지, 클릭 가능한 요소에 hover 상태가 있는지, 위 네 가지 폭에서 깨지지 않는지.
