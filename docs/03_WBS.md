## 작업 순서와 의존 관계

```mermaid
flowchart LR
    A[1. 분석] --> B[2. 설계]
    B --> C[3. 백엔드 구현]
    B --> E[5. 프론트엔드 구현]
    C --> D[4. AI 서버 구현]
    C --> E
    D --> E
    E --> F[6. 검증]
    F --> G[7. 마무리]
```

- 백엔드의 Spring AI(3.7)는 관광지·플랜 서비스(3.3, 3.4)를 Tool로 재사용하므로 그 뒤에 진행했다.
- 문서 검색 Tool은 AI 서버(4.1)의 `/search`를 호출하므로 두 작업을 이어서 진행했다.
- 프론트엔드는 API가 확정된 뒤 화면 단위로 구현했다.
